This project analyses 3,700+ Airbnb listings in Brisbane to uncover the key factors influencing listing prices and identify meaningful patterns across the local short-term rental market.

The analysis combines data cleaning, exploratory analysis, feature engineering, visualisation, and predictive modelling to examine how property characteristics, location, host attributes, and availability relate to pricing.

Beyond prediction, the project focuses on turning granular listing data into clear market insights that can support pricing strategy and business decision-making. Findings highlight differences in pricing across property types, locations, accommodation capacity, and demand-related characteristics, providing a data-driven view of the Brisbane Airbnb market.

Key skills: Python · Pandas · Data Cleaning · Exploratory Data Analysis · Data Visualisation · Feature Engineering · Market Analysis · Predictive Modelling
